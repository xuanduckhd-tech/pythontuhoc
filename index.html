Trọng Tâm Lý Thuyết & Luyện Tập Midterm

Phần này tổng hợp các kiến thức cốt lõi và các bài tập trắc nghiệm hóc búa mô phỏng cấu trúc đề thi giấy (Lec 1 - 14).

1. Kiểu Dữ Liệu & Biểu Thức

  • Toán tử chia: / luôn trả về float. // chia lấy phần nguyên. % chia lấy dư.
  • Short-circuit: A and B, nếu A sai thì không cần xét B.

2. Hàm & Scope

  • Local Scope (Cục bộ): Biến tạo trong hàm chỉ tồn tại trong hàm.
  • Global Scope (Toàn cục): Để đổi giá trị biến global trong hàm, dùng từ khóa global.

3. Khung Kích Hoạt & Bộ Nhớ

  • Call Stack: Chứa Activation Records. Hàm kết thúc -> Frame bị hủy.
  • Heap Space: Nơi lưu trữ thực sự của các đối tượng (như List, String).
  • Toán tử: == so sánh giá trị, is so sánh địa chỉ vùng nhớ Heap.

4. Mutability & Aliasing

  • Immutable (Bất biến): Chuỗi, Int. Sửa giá trị = sinh ra object mới.
  • Mutable (Có thể đổi): List. Thay đổi trực tiếp (in-place).
  • Aliasing (Đồng danh): b = a. Cả hai trỏ về 1 List. Để tránh, dùng b = a.copy().

5. Bất biến vòng lặp (Loop Invariants)

1. Khởi tạo (Initialization):
Đúng TRƯỚC lần lặp đầu tiên.
2. Duy trì (Maintenance):
Nếu đúng trước vòng lặp thứ i, nó vẫn đúng SAU vòng lặp i.
3. Kết thúc (Termination):
Khi dừng, điều kiện này chứng minh thuật toán đã đúng.

Đề Cương & Tài Liệu Tham Khảo Môn Học

Tổng hợp giáo trình, tài liệu tham khảo chính thống và chuẩn đầu ra môn học (CLO).

Giáo trình chính

Think Python 2e (Allen B. Downey)

Sách hướng dẫn nền tảng tư duy máy tính và lập trình Python cơ bản. Bao gồm từ khái niệm biến, hàm, chuỗi cho đến danh sách và vòng lặp while.

Tài liệu tham khảo sâu

Introduction to Computation and Programming Using Python (John V. Guttag)

Tài liệu nâng cao tập trung vào mô hình bộ nhớ (Global space, Heap space, Call stack, Activation Records) và tư duy thuật toán.
